CDC Methodology

Compilation-Decompilation-Comparison: The scientific approach to reverse engineering validation

Why CDC Testing?

Traditional reverse engineering relies on subjective analysis and manual verification. CDC testing transforms this into an objective, measurable process.

The Problem
  • "Our tools work... we think"
  • Manual verification is time-consuming and error-prone
  • No way to measure analysis quality
  • Hard to detect regressions in tool updates
The CDC Solution
  • Measurable accuracy: Empirical validation of analysis results
  • Automated testing: Continuous validation of tool quality
  • Regression detection: Catches when tools break
  • Confidence metrics: Quantified trust in analysis results

How CDC Works

1. Compile

Take known source code and compile it into a binary executable using standard compilers (GCC, MSVC, etc.)

Example:
hello_world.c → gcc -o hello.exe hello_world.c
2. Decompile

Analyze the binary using reverse engineering tools to extract information, functions, strings, and structure

Tools:
Ghidra, radare2, IDA Pro, Binwalk, strings, entropy analysis
3. Compare

Compare the decompiled results against the original source to validate that critical information is preserved

Validation:
String extraction (80%+), function detection, control flow preservation

Real-World Applications

Malware Analysis

Validate that malware analysis tools correctly identify suspicious patterns, network connections, and obfuscation techniques.

Example: Network Malware Detection
connect("blofeld.org", 666)
download("malware.exe")
→ 🚨 MALWARE ALERT! Suspicious network activity detected
Vulnerability Research

Ensure that reverse engineering tools correctly identify vulnerable functions, unsafe API usage, and exploitable code patterns.

Example: Buffer Overflow Detection
strcpy(buffer, user_input)
gets(unchecked_buffer)
→ ⚠️ Unsafe API usage detected
Tool Validation

Verify that reverse engineering tools maintain accuracy across versions and correctly handle various binary formats.

Example: Regression Testing

→ ✅ Tool quality improved
