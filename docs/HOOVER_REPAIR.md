# Hoover repair plan — whirr, won't start (2026-10-31)

Status: Tier 1 revive, live fault. Intake stub: `docs/intake-hoover.md`.
**Blocked on: make + model from the rating plate** (upright/canister/robot?).
No parts ordered before diagnosis — cheap × wrong is still waste.

## Diagnostic order (mechanical first, always unplugged)

1. **Airflow path.** Empty bin. Pull filters, wash, dry 24 h (damp filter =
   blockage). Rod the hose, check cuffs and bends for the classic sock.
2. **Brushroll.** Flip, pull, cut hair-wrap off end caps and bearings. Burnt
   rubber smell = snapped belt (motor whirrs, nothing turns).
3. **Thermal cutout.** Unplug 30–60 min to reset (clean first or it re-trips).
   Some units have a physical reset button — plate/manual says.
4. **Impeller chamber.** Whirr + power present = possibly stalled fan. Unplug,
   inspect for debris. This chamber can eat fingers — tools, not hands.
5. **Electrical (only if 1–4 clear).** Carbon brushes (5 years wears them to
   nubs — cheap), one-shot thermal fuse (cheap), then switch continuity and
   cord-reel damage last. Measure, don't guess.

## Close-out

- Fix confirmed by: full-bin test run, no cutout trip, no smell.
- Log the fault + fix in the intake stub (future fleet self-diagnosis data).
- Escalation: motor windings shorted (burnt varnish smell, dead phase) =
  donor motor or Tier 3 territory, not a brush job.
