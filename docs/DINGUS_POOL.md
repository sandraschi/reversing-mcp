# Dingus pool — revivable / improvable / AI-ifyable (2026-10-31)

Scored by rarity = (no driver) x (no dump) x (custom silicon). Undumped ROMs
jump the queue. Intake rule stands: no work without a model number.

- Dead MIDI keyboards as controllers (M1 pattern: keybed + panel survive).
- Cassette decks as LLM-driven lo-fi samplers (bias/ EQ as effect params).
- 486/beige desktops: the XT we lost, reconstituted — 86Box oracle first.
- CRT pocket TVs as chatbot faces (composite from a Pi Zero, zero mod).

## Textile (actuator story)

- Early automated sewing machine: needle sensors, feed steppers, pattern ROMs
  nobody has read. The full sense-compute-actuate loop in one chassis.

## Purely mechanical metarevival (ZERO modification — Robbie is the hands)

Rule: object stays 100% stock; robot operates it; camera verifies the effect.
Ops exist today: `gripper_open/close`, camera PTZ, `say`, SLAM waypoints,
missions (`yahboom-mcp`).

1. **Brass banker lamp (hello-world).** SLAM waypoint → PTZ aim → gripper
   pulls chain / flips toggle → camera brightness-delta confirms → Robbie
   announces. Start with a big toggle; graduate to the pull-chain.
2. Thermostat dials (before/after camera read of the setpoint).
3. Flip clocks and metronomes (wind + observe, timing verified on camera).
4. Rotary phone (ambitious: gripper dialing, audio confirmation).
5. Record player (delicate: tonearm assist only, human places the needle).

Metarevival doctrine: the demo is the receipt — navigate, actuate, verify,
announce. If the camera can't verify it, it didn't happen.
